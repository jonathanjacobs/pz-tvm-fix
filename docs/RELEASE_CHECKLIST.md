# Release checklist

Do not call the addon ready beyond alpha until each applicable item has evidence.

- [ ] `VERSION`, `CHANGELOG.md`, both `mod.info` files, and Workshop metadata agree.
- [ ] Exact TVM and Project Zomboid compatibility versions are recorded.
- [ ] Baseline, pass-through, event-mode, multiplayer, save/load, and addon-removal tests are recorded.
- [ ] Public claims match [`VALIDATION_HISTORY.md`](VALIDATION_HISTORY.md).
- [ ] Package contains no logs, saves, credentials, private configuration, source-control metadata, decompiled source, or extracted assets.
- [ ] Third-party rights, attribution, Project Zomboid policy, Workshop metadata, backup, and rollback instructions are current.
