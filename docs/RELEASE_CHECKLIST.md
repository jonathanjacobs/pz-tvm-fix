# Release checklist

- [ ] `VERSION`, `CHANGELOG.md`, and all applicable `mod.info` files agree.
- [ ] Exact TVM and Project Zomboid compatibility boundary is documented.
- [ ] Traffic and save/uninstall scenarios in `TESTING.md` were run and recorded.
- [ ] Claims match collected evidence.
- [ ] Package contains no saves, logs, private configuration, source-control metadata, decompiled source, or extracted assets.
- [ ] Third-party rights and attribution are documented.
- [ ] Project Zomboid Modding Policy was reviewed for intended distribution.
- [ ] Deployment, backup, and rollback steps are current.
